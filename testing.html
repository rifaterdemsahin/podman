✅ How to Test Your Podman Installation

Why can't I "see" Podman?

Unlike Docker Desktop, which has a graphical user interface (GUI) running in your Mac's menu bar, Podman is a daemonless, CLI-first tool. This means you will not see an app icon running in your dock. It runs efficiently in the background as a lightweight QEMU virtual machine.

If you prefer a GUI to see your containers visually, you can install Podman Desktop, but it is strictly optional.

Step 1: Verify the CLI is Installed

Open your terminal and check if the podman command exists on your system:

podman --version

Expected Output: podman version 5.x.x

Step 2: Check the Podman Machine Status

Because macOS isn't Linux, Podman needs a tiny background VM to run containers. Check if it's running:

podman machine list

Expected Output: You should see podman-machine-default with a * next to it, and the state should say Currently running.

If it's stopped, start it:

podman machine start

Step 3: Run a Test Container

The ultimate test is pulling and running a container from the internet. Run the standard hello-world container:

podman run --rm hello-world

Expected Output: A message saying Hello from Docker! This message shows that your installation appears to be working correctly.

Step 4: Check Active Containers

To see containers that are currently running in the background (like our ArangoDB instance):

podman ps
