🐋 Concept: Podman

What is Podman?

Podman is a daemonless container engine for developing, managing, and running OCI Containers on your Linux System (or macOS/Windows via Podman Machine). It serves as a direct drop-in replacement for Docker.

Why use it over Docker Desktop? [🤔 Rationale]

  • Daemonless Architecture: It doesn't require a persistent background daemon running as root, making it more secure and less resource-heavy.
  • Licensing: Podman is fully open-source, allowing you to avoid commercial licensing issues present with Docker Desktop for large enterprises.
  • Pods natively: Podman can group containers together into "Pods" (similar to Kubernetes pods), which share the same network, IP address, and port mappings.

Podman Machine on macOS

Since containers natively rely on the Linux kernel, Podman on macOS utilizes podman-machine. This spins up a lightweight Fedora CoreOS virtual machine (using QEMU/Apple Hypervisor) to provide the necessary Linux kernel to your containers. It also smoothly handles cross-architecture emulation (e.g., running x86_64/AMD64 containers on Apple Silicon M-series chips).
