🖥️ Podman Desktop

What is Podman Desktop?

If you miss the visual interface of Docker Desktop, Podman Desktop is the official open-source GUI for managing your Podman containers, images, and pods without needing to use the terminal.

Installation via Homebrew

You can easily install Podman Desktop using Homebrew alongside your existing CLI installation.

brew install podman-desktop

Why Use the Desktop App?

  • Visual Container Management: Easily start, stop, and delete containers with a click.
  • Real-time Logs: View ArangoDB or your Python dashboard logs visually without running podman logs -f.
  • Network & Volume Inspector: View exposed ports and mounted directories (like our nz-energy.json data volume).
  • Pod Generation: Generate Kubernetes YAML from your locally running containers natively.
