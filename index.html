🚀 The Edge AI Architecture Hub

What is this project?

Welcome to the Edge AI Architecture Hub. This project serves as a comprehensive, interactive documentation site and sandbox for modern, edge-deployed artificial intelligence and graph database infrastructures.

Instead of relying on heavy, centralized cloud providers, this project demonstrates how to build, test, and deploy ultra-fast AI backends using lightweight technologies that push compute physically closer to the user.

The Tech Stack

We combine four cutting-edge technologies to achieve this:

  • Podman: A daemonless, open-source alternative to Docker for running secure local containers.
  • ArangoDB & AQL: A multi-model graph database perfect for mapping semantic "Second Brains" and Contextual AI relationships.
  • Fly.io: A global edge network that transforms your containers into micro-VMs running worldwide.
  • Local UI: This exact site—a static, responsive HTML/CSS dashboard generated to explain the stack.

☁️ Fly.io Deployment Integration

This repository is configured to deploy directly to Fly.io as a static Python web server. To deploy it and interact with it on the cloud:

# 1. Login to Fly.io fly auth login # 2. Launch and deploy the application fly launch --name podman-arango-dashboard fly deploy

Once deployed, you can visit your remote dashboard using fly open.

🛠️ Stage 1: Podman Installation [🤔 Rationale]

brew install podman flyctl podman machine init --cpus 2 --memory 4096 --rootful=false podman machine start

🥑 Stage 2: ArangoDB Container Deployment [🤔 Rationale]

podman run -d -p 8529:8529 -e ARANGO_ROOT_PASSWORD=password --name arango arangodb
