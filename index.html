Stage 1: Podman Installation & Initialization

Here are the steps we took to get Podman running on macOS:

# 1. Install Podman and Flyctl brew install podman flyctl # 2. Initialize a Podman machine (allocated 2 CPUs and 4GB memory) podman machine init --cpus 2 --memory 4096 --rootful=false # 3. Start the Podman machine podman machine start

Stage 2: ArangoDB Container Deployment

We pulled the official ArangoDB image and started it up with the following command:

podman run -d -p 8529:8529 -e ARANGO_ROOT_PASSWORD=password --name arango arangodb

Stage 3: ArangoDB Use Cases (arango.ai)

ArangoDB is a scalable, fully managed multi-model database (document, graph, and key-value). Here is how you can use it locally with Podman:

1. Graph Neural Networks & AI App Development

Using Arango.ai integrations, developers can spin up a local graph database via Podman, inject test network data, and run AQL (ArangoDB Query Language) queries to test machine learning models locally before deploying them to Fly.io.

2. Multi-Model Data Testing

Instead of running multiple containers for Redis (Key-Value) and MongoDB (Document), you can run a single ArangoDB container locally to handle unstructured JSON documents alongside highly relational graph data structures, significantly reducing local memory usage (fitting perfectly within our 4GB Podman limit).

3. Testing AQL Query Performance

Use the local container to access the ArangoDB Web Interface (on port 8529) to visualize graphs and EXPLAIN complex AQL queries. Because Podman closely mirrors Linux container environments on cloud providers, local performance tuning provides highly accurate estimates for production deployments.
